プライバシーポリシー

ヤスネ帳（以下「当サイト」）は、利用される方の個人情報を大切に扱います。当サイトでの情報の扱いについて、以下のとおり定めます。

1. 集める情報

  • 当サイトは、会員登録やログインの仕組みを持っていません。閲覧するだけで、名前やメールアドレスなどを集めることはありません。
  • お問い合わせフォームから連絡をいただいた場合は、入力された内容（お名前、メールアドレス、お問い合わせ内容など）を受け取ります。
  • 当サイトは現在、アクセス解析ツールを使っていません。使うことになった場合は、このページでお知らせします。

2. 情報の使い方

お問い合わせでいただいた情報は、返信や対応のためだけに使います。法律で求められる場合を除き、本人の同意なく第三者に渡すことはありません。

3. 広告（アフィリエイト）について

  • 当サイトは、バリューコマース株式会社のアフィリエイトプログラムなどに参加しています。商品へのリンクを経由して購入された場合、運営者に紹介料が支払われることがあります。
  • リンク先のお店や広告サービスは、購入の計測のためにCookie（クッキー）を使うことがあります。Cookieで集められる情報や使い方は、各社のプライバシーポリシーをご確認ください。Cookieはブラウザの設定で無効にできます。

4. 外部サービスの利用

  • 商品情報は、LINEヤフー株式会社が提供する「Yahoo!ショッピング 商品検索API」から取得しています。
  • ページの文字の表示に Google Fonts を、掲載内容の一部の管理に Google スプレッドシートを使っています。表示のときに、これらのサービスへ通信が発生することがあります。
  • サイトは GitHub Pages で公開しています。

5. 免責事項

  • 掲載している価格・ポイント・送料・在庫は、更新した時点の情報です。実際の内容と違う場合があるので、購入前に必ず販売ページでご確認ください。
  • 「実質価格」「キャンペーン込み（最大）」は、ポイントを値引きと考えて計算した目安です。キャンペーンの条件や上限によって、実際にもらえるポイントは変わります。
  • 当サイトの情報を使ったことで起きた損害について、運営者は責任を負いかねます。商品の購入・返品・トラブルについては、各販売店にお問い合わせください。

6. 著作権

当サイトの文章・キャラクター画像の著作権は運営者に帰属します。商品画像・商品名の権利は、各メーカー・販売店に帰属します。

7. お問い合わせ・改定

このポリシーについてのお問い合わせは、お問い合わせフォームからお願いします。内容は必要に応じて見直し、このページで更新します。
